# StockCheckbox

Case à cocher d'une des 5 actions dans le simulateur, avec le nom, le code boursier et la pastille de couleur du titre.

- La pastille reprend la couleur fixe du titre dans les graphiques (`chart-dsy`, `chart-tte`, `chart-cap`, `chart-rms`, `chart-ai`).
- Cochée : fond `brand-soft`, bordure `brand`.
- Toute la ligne est cliquable (élément `label`), pas seulement la case.
